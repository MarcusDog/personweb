## 当系统变复杂，界面必须承担解释责任

在 AI Agent 项目里，结果页往往只展示“输出”。  
但真正影响信任的，往往是系统如何把判断过程折叠成一个可以理解的界面。

### 三种常见误区

1. 把所有中间状态都展示出来
2. 完全不展示理由
3. 用华丽视觉掩盖不清晰的结构

## 研究不是文档，而是交互前提

研究真正有价值的时候，不是它被整理进 PDF，而是它决定了哪些信息要被放到界面上，哪些不要。

<!--lang:en-->
## When Systems Get Complex, Interfaces Must Explain

In many AI agent products, the result page shows only “the output.”  
But trust is usually shaped by how the system folds judgment into an understandable surface.

### Three Common Mistakes

1. Showing every intermediate state
2. Showing no reason at all
3. Hiding weak structure behind decorative visuals

## Research Is an Interaction Condition

Research matters most not when it sits in a PDF, but when it decides what should appear in the interface and what should stay hidden.
