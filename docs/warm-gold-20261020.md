# 奶油暖金升级（2026-10-20）

## 本次交付

前台使用奶油白 `#F7F4EE`、抬升表面 `#FFFDF8`、暖墨 `#25231F`，以香槟金细线和深金文字点缀。主按钮回到深墨色。原始头像、文章正文、16 个项目及真实截图保留。

首页保持文章、项目、书架、个人介绍的顺序；无随想时书架占满该行。项目采用错落的双列组合，普通文章列表不再重复氛围图。关于页用连续的“现在关注的事”章节替代功能菜单。页脚改为邮件与订阅在上、导航和版权在下，移除山水背景和重复说明。

动效复用 Framer Motion：首屏按块错开、章节单次渐入、头像与精选图片轻量景深。手机不启用持续视差；系统减少动态效果时停用位移、缩放和 CSS 动画。没有滚动劫持。

新叙述按 humanizer-zh 规则保持简短、具体；没有改写现有技术文章。

## 真实书封与写作台

六本现有书籍已逐一核对 ISBN、作者和版本。中文展示名对应英文版书封的书，在详情中明确标注英文版；保持全部“想读”、零进度，不导入虚构笔记。

书架：桌面三列、平板与手机两列；支持 `/reading?status=wish&book=slug`。详情使用原生模态对话框，支持 Escape、点击背景关闭和焦点恢复，关闭后保留筛选。

写作台书籍编辑增加 ISBN、原文书名、书封来源、版本、确认状态与候选选择。输入停止 900ms 后查询：ISBN 校验后查精确版本；无 ISBN 时只有标题、作者及单一版本都明确才自动采用。多版本必须人工确认。查询晚返回不会覆盖改名或手动上传的封面。

新书没有封面也能存草稿，但发布需要已确认的真实封面。自动匹配仅影响草稿，手动上传和选择优先。失败时保留原文，可重试或上传。

### 服务说明

- 受保护接口：`POST /api/admin/books/cover-lookup`。
- Open Library 默认来源，无需密钥；Google Books 仅在配置 `GOOGLE_BOOKS_API_KEY` 后补充。
- 外部请求超时 8 秒；上游请求间隔至少 1.1 秒；管理员每分钟最多 12 次查询，返回 `Retry-After`。
- SQLite 缓存：成功与候选 24 小时，无结果 1 小时；失败不写入缓存，并合并相同的在途查询。
- 遵循[官方书封要求](https://openlibrary.org/dev/docs/api/covers)：前台直接引用正式书封地址，不下载镜像。部分图片跳转到 Internet Archive，因此 CSP 只额外允许 Open Library、Internet Archive 及其子域和 Google Books 图片域。
- 部署若需代理，在启动 Node **之前**设置进程环境 `NODE_USE_ENV_PROXY=1`、`HTTPS_PROXY` / `HTTP_PROXY`，并设置 `NO_PROXY=localhost,127.0.0.1`。需要 Node 24.5+；代码中没有本机代理地址。示例见 `.env.example`。
- 既有书籍受控补封面：一次性迁移，仅处理原始 seed id、标题和作者仍一致且没有封面的条目；仅补相关字段，不改变正文、阅读状态、公开时间或手动封面。迁移标记防止重启时再次干预用户修改。
- 修改前 SQLite 备份：`server/data/backups/warm-gold-1792471173621/personweb.db`。上传素材未做迁移或删除。
