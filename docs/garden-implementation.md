# 写作台与内容维护

## 打开网站

本次完整预览运行在 `http://localhost:4191/?v=warm-gold-20261020`，写作台在 `/studio`。奶油暖金视觉和真实书封说明见 [本次升级](warm-gold-20261020.md)。如果已有浏览器仍显示旧页面，请按 Ctrl + Shift + R 强制刷新。

常规开发：`pnpm dev:server` 启动 Express 3001，`pnpm dev` 启动 Vite 5173。构建后，Express 可同时提供完整站点，不需要单独运行 Vite。

```powershell
pnpm build
$env:PORT='4191'
pnpm start
```

账号默认 `xiaotian`，首次随机密码写入 `server/data/admin-secret.txt`。该文件和数据库均被 Git 忽略。部署前在服务端 `.env` 配置自己的强密码与 HTTPS；不要把凭据复制进源码。服务重启会使现有登录会话失效，重新登录即可，内容不受影响。

## 写文章

新增写作工具：技术分析、项目复盘、读书与随想模板（追加正文）；可视化 / Markdown 源码切换；字数、预计阅读时长与结构目录；专注模式（Esc 退出）；发布检查清单。Ctrl / ⌘ S 保存草稿，Alt P 切换预览。源码编辑同样保存结构化文档，自动保存与发布隔离不变。

1. 从文章页的“登录管理／写文章”或导航的“写作台”进入。
2. 选择文章，新增一篇。只填写中文即可，英文是选填项。
3. 编辑器支持二、三级标题、列表、引用、链接、代码块、表格，以及粘贴、拖入或上传图片。素材库中的图片也能插入当前光标位置。封面与正文图片单独设置。
4. 停止输入约 1.4 秒后自动保存。服务暂时不可用时，本机保留未同步内容，重新打开相同内容可恢复；也可以先导出 Markdown。登录过期可在新窗口重新登录后重试。
5. 点击预览查看正文排版，再发布。已发布内容的修改只进入草稿，点击“更新发布”才改变前台。撤回保留草稿，删除会移除记录，删除前如需留档请先导出。

已发布内容的 slug 不直接修改，以保护原文章链接。新文章可在首次发布前编辑 slug，支持中文、数字、横线和下划线。

## 其他内容

- 随想：正文、日期和标签，适合简短记录。
- 书架：书名、作者、封面、在读／已读／想读、进度、个人笔记与关联文章 slug。网站没有导入设计图里的示例阅读记录。
- 项目：简介、角色、问题、实现方式、进展、分章节说明、截图图注、源码／演示链接。可调整首页与合作页开关；首页展示顺序在设置中选择。
- 素材库：上传 PNG、JPEG、WebP、GIF，单张不超过 5MB，保存原件并生成 WebP；可以编辑归属项目、图注和来源类型。生成素材不应标为实际截图。
- 留言：查看联系页收到的消息，按正文、称呼、话题和联系方式搜索，筛选已读／未读，复制联系方式或打开邮件回复；可查看关联项目、时间与预算选项。留言不会公开展示，也不会进入 RSS。
- 设置：站点名称、首页介绍、关于文本、首页项目顺序、模型状态与连接测试。

## RSS、书架与新增内容

`/subscribe` 提供复制订阅地址的说明页面。综合源 `/rss.xml` 包含文章与书架；文章源 `/feeds/articles.xml`、读书源 `/feeds/reading.xml` 可分别订阅。RSS 提供安全渲染的全文，保留既有文章 URL 标识，草稿修改不会改变公开内容或公开更新时间。

新增四篇技术分析围绕上下文管理、Agent 故障恢复、RAG 证据链、本地优先边界；原始资料链接放在正文里。六本科技／人文书籍全部标记为想读，进度为零，不虚构读后感。导入逻辑按版本和 slug 幂等执行，不覆盖后台修改，删除后重启也不会重新导入。

## AI 建议与事实边界

排版、润色、摘要和翻译全部使用 `server/prompts/editorial-assistant.cjs` 的统一提示词，遵循自然、具体、不编造事实的编辑口径。输入正文中的指令被视为材料，而非执行授权。

配置 `.env` 中的 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 后重启，再到设置测试连接。密钥只保留在服务端。建议稿先展示，采用后仍可撤销；失败不会改变原稿。当前本地未配置模型密钥，因此只验证了未配置／失败时的安全恢复路径，未声称完成真实模型调用。

## 数据与迁移

- 数据：`server/data/personweb.db`。新内容存储在 `garden_content`，保留独立 published／draft JSON；原 `journal_posts` 表未删除。
- 首次迁移：按现有 slug 导入，不在每次启动时覆盖内容。保留全部旧文章链接与 14 个项目，另并入 WeChat Auto、AI Closet，共 16 个项目。
- 迁移前备份：`server/data/backups/pre-garden-20261019`，包括 SQLite 一致性备份与上传素材。
- 日常备份：使用 SQLite backup API 备份数据库，并一起复制 `public/uploads`。运行中不要只复制主 `.db` 而遗漏 WAL。
- 固定素材：`public/garden/manifest.json` 记录归属、来源、尺寸、原件与图注；`scripts/prepare-garden.mjs`、`scripts/enrich-garden.mjs` 用于本机素材整理，不是日常发布命令。它们引用本机项目路径，部署时不需要执行。
- RSS 和 sitemap：Express 动态输出 `/rss.xml`、`/sitemap.xml`。API 不缓存；HTML 和非哈希素材重新校验，带哈希的代码文件可长期缓存。
