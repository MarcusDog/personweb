# 动效策略

## Motion Thesis

动效服务于存在感、层级与气氛，不服务于炫技。

## Rules

- hover: `200–300ms`
- entrance: `600–900ms`
- ambient: `12s–24s`
- 支持 `prefers-reduced-motion`

## Applied Motions

- Prelude 的文字显现与金属光扫
- 首页背景的低振幅流动
- 卡片与链接 hover 的微亮与微抬升
- 页面块进入视窗时的轻微上浮与淡入

## Explicitly Avoided

- bounce
- 强 3D 翻转
- 大幅位移飞入
- 粒子、故障、霓虹赛博特效
