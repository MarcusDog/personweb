# 设计说明

## Site Positioning

这不是模板化作品集，也不是简历页。  
它是一套长期可扩展的个人品牌底座，围绕三个核心维度展开：

- AI Agent 项目展示
- 持续写作与研究判断
- 商务合作入口

## 首页策略

- 首屏只讲一个命题：`小天Aya｜BemsZzz`
- 价值表达偏商业落地，不堆研究者标签
- 研究者与 AI 学习者身份进入 About、Project Detail、Journal 深处展开

## 内页策略

- Projects 更像高质量案例档案
- Journal 更像出版物目录与文章页
- Contact 更像品牌最后一页，而不是普通联系方式集合

## 审美约束

高级感 = 克制 + 比例 + 留白 + 质感 + 排版 + 节奏

明确避免：

- chips、序号、protocol 式装饰
- 围绕标题堆素材
- SaaS landing page 的三栏功能解释
- 低级黑金发光与假科技视觉
