# 中文排版策略

## 核心原则

- 中文标题按视觉而不是按浏览器默认断行
- 中英混排保持节奏统一
- 正文宽度按阅读而不是按屏幕最大化铺开

## 实现方式

- 标题统一使用 `text-wrap: balance`
- 显示标题使用 `line-break: strict`
- 正文使用更高的 `line-height`
- 阅读区 `max-inline-size` 控制在约 `68ch` 到 `70ch`
- 标题与正文拆成不同的字重和字距策略

## 页面差异

- 首页标题：更大、更紧凑、更像海报
- 内页页头：仍为 serif，但呼吸感更强
- Journal 正文：最安静、最克制，动画最少
